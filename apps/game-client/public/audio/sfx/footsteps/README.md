# Footstep Sounds

Per-terrain-type footstep sets. The game selects the correct set based on the surface material under the player. Provide 4+ variants per terrain to avoid repetition.

## Needed Sets

| Terrain | Files | Description |
|---------|-------|-------------|
| Dirt | `footstep_dirt_01-04.ogg` | Soft earth, forest paths |
| Stone | `footstep_stone_01-04.ogg` | Cobblestone roads, ruins |
| Grass | `footstep_grass_01-04.ogg` | Open fields, meadows |
| Wood | `footstep_wood_01-04.ogg` | Wooden floors, bridges |
| Gravel | `footstep_gravel_01-04.ogg` | Rocky terrain, mountain paths |
| Water (shallow) | `footstep_water_01-04.ogg` | Splashing through puddles/streams |
| Sand | `footstep_sand_01-04.ogg` | Desert, beach areas |
| Snow | `footstep_snow_01-04.ogg` | Winter zones |

Each set also needs a sprint variant (louder, heavier):
`sprint_dirt_01-03.ogg`, `sprint_stone_01-03.ogg`, etc.
