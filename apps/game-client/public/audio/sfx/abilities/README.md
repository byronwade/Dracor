# Ability Sound Effects

Dragon Memory activations, racial abilities, and skill sounds.

## Dragon Memory Sounds

| File | Description |
|------|-------------|
| `memory_ember_activate.ogg` | Ember memory activation (fire surge) |
| `memory_ember_loop.ogg` | Ember memory sustained (crackling fire loop) |
| `memory_stone_activate.ogg` | Stone memory activation (deep rumble) |
| `memory_stone_loop.ogg` | Stone memory sustained (grinding stone loop) |
| `memory_storm_activate.ogg` | Storm memory activation (thunder crack) |
| `memory_storm_loop.ogg` | Storm memory sustained (electrical hum loop) |

## General Ability Sounds

| File | Description |
|------|-------------|
| `ability_ready.ogg` | Ability comes off cooldown |
| `ability_fail.ogg` | Not enough resource / on cooldown |
| `dodge_roll.ogg` | Dodge roll whoosh |
| `sprint_start.ogg` | Sprint activation burst |
| `heal_self.ogg` | Self-heal activation |
| `buff_apply.ogg` | Buff/enhancement applied |
| `buff_expire.ogg` | Buff wears off |
| `debuff_apply.ogg` | Negative effect applied to player |
