# UI Sound Effects

Interface interaction sounds. Short, clean, non-intrusive.

## Needed Sounds

| File | Description |
|------|-------------|
| `button_click.ogg` | General button press |
| `button_hover.ogg` | Mouse hover on interactive element |
| `menu_open.ogg` | Opening a menu panel |
| `menu_close.ogg` | Closing a menu panel |
| `tab_switch.ogg` | Switching between tabs |
| `notification.ogg` | Alert or new message |
| `error.ogg` | Invalid action / error feedback |
| `confirm.ogg` | Confirm action (accept quest, etc.) |
| `cancel.ogg` | Cancel / decline |
| `level_up.ogg` | Level up fanfare |
| `quest_complete.ogg` | Quest completion chime |
| `quest_accept.ogg` | Accepting a new quest |
| `chat_message.ogg` | Incoming chat message ping |
| `player_join.ogg` | Player joins the world |
| `player_leave.ogg` | Player leaves the world |
