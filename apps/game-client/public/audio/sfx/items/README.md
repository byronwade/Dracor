# Item Sound Effects

Sounds for picking up, dropping, equipping, and using items.

## Needed Sounds

| File | Description |
|------|-------------|
| `pickup_generic.ogg` | Picking up a general item |
| `pickup_coin.ogg` | Gold/currency pickup (satisfying clink) |
| `pickup_weapon.ogg` | Weapon acquired |
| `pickup_armor.ogg` | Armor piece acquired |
| `equip_weapon.ogg` | Equipping a weapon (draw sound) |
| `equip_armor_light.ogg` | Equipping leather/cloth |
| `equip_armor_heavy.ogg` | Equipping plate/chain |
| `unequip.ogg` | Removing equipment |
| `potion_drink.ogg` | Consuming a health/mana potion |
| `potion_break.ogg` | Potion bottle breaking (thrown) |
| `scroll_use.ogg` | Using a scroll |
| `drop_item.ogg` | Dropping an item on ground |
| `inventory_open.ogg` | Opening inventory |
| `inventory_move.ogg` | Moving item between slots |
