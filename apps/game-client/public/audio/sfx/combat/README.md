# Combat Sound Effects

Weapon swings, impacts, projectiles, and magic sounds. Multiple variants per sound prevent repetition.

```
combat/
  melee/       Sword swings, axe chops, hammer thuds, dagger slashes
  ranged/      Bow draw, arrow release, arrow impact, arrow whistle
  magic/       Staff channel, spell cast, spell impact, aura sounds
  impacts/     Hit flesh, hit armor, hit shield, critical hit, kill
```

## Needed Sounds (3+ variants each)

### Melee
- `swing_light_01-03.ogg` — Fast weapon swing (dagger, arming sword)
- `swing_heavy_01-03.ogg` — Heavy weapon swing (greatsword, hammer, axe)
- `swing_spear_01-03.ogg` — Spear thrust
- `parry_01-03.ogg` — Metal-on-metal parry
- `block_01-03.ogg` — Shield/weapon block impact

### Ranged
- `bow_draw_01-02.ogg` — Drawing the bowstring
- `bow_release_01-03.ogg` — Arrow leaving the bow
- `arrow_fly_01-02.ogg` — Arrow in flight (looping)
- `arrow_hit_01-03.ogg` — Arrow striking target

### Magic
- `staff_channel_01-02.ogg` — Channeling energy (looping)
- `spell_fire_01-03.ogg` — Fire spell cast
- `spell_lightning_01-03.ogg` — Lightning spell cast
- `spell_stone_01-03.ogg` — Stone/earth spell cast

### Impacts
- `hit_flesh_01-04.ogg` — Striking an unarmored target
- `hit_armor_01-03.ogg` — Striking armored target
- `hit_critical_01-02.ogg` — Critical hit (louder, more dramatic)
- `kill_01-03.ogg` — Death blow (dramatic punctuation)
