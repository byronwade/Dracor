# Music

Background music organized by game context. Tracks crossfade when transitioning between states.

## Folders

| Folder | Trigger | Notes |
|--------|---------|-------|
| `exploration/` | Player enters a zone | Calm, atmospheric, loops seamlessly |
| `combat/` | Enemy engagement starts | Intense, drives urgency, loops until combat ends |
| `town/` | Player enters safe zone | Warm, social, inviting |
| `menu/` | Main menu, character select | Sets the tone for new players |

## Needed Tracks

### Exploration
- `ironvale_outskirts.ogg` — Dark pine forest, frontier tension, quiet beauty

### Combat
- `combat_standard.ogg` — General enemy encounter
- `combat_boss.ogg` — Boss fight (more intense, dramatic)

### Town
- `ironvale_town.ogg` — Inside Ironvale walls, safe and warm

### Menu
- `main_menu.ogg` — Title screen / character select
