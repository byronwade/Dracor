# NPC Models

Non-player characters: quest givers, merchants, townsfolk, guards.

## Naming Convention

`{npc_name}.glb` — e.g., `orin_ash.glb`, `guard_ironvale.glb`, `merchant_general.glb`

## Requirements

- Max 8,000 triangles per NPC
- Include skeleton for idle/talk animations
- Can share the player character skeleton for humanoid NPCs
- Unique NPCs (named quest givers) can have more detail than generic townsfolk
