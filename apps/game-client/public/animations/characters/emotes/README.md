# Emote Animations

Social and expressive animations triggered by player commands.

## Standard Emotes

| File | Loop | Description |
|------|------|-------------|
| `emote_wave.glb` | No | Friendly wave |
| `emote_bow.glb` | No | Respectful bow |
| `emote_sit.glb` | Yes | Sit on ground (looping idle) |
| `emote_cheer.glb` | No | Victory celebration |
| `emote_point.glb` | No | Point forward |
| `emote_dance_01.glb` | Yes | Dance loop (casual) |
| `emote_dance_02.glb` | Yes | Dance loop (energetic) |
| `emote_salute.glb` | No | Military salute |
| `emote_laugh.glb` | No | Laughing |
| `emote_shrug.glb` | No | Confused shrug |
| `emote_flex.glb` | No | Show off muscles |
| `emote_meditate.glb` | Yes | Seated meditation (looping) |
