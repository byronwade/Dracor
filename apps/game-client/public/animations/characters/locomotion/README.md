# Locomotion Animations

Core movement animations shared across all playable races.

## Required Set

| File | Loop | Description |
|------|------|-------------|
| `idle.glb` | Yes | Standing idle with subtle breathing/sway |
| `walk_forward.glb` | Yes | Standard walk cycle |
| `walk_backward.glb` | Yes | Backpedal |
| `walk_left.glb` | Yes | Strafe left |
| `walk_right.glb` | Yes | Strafe right |
| `run_forward.glb` | Yes | Jogging pace |
| `sprint_forward.glb` | Yes | Full sprint |
| `jump_start.glb` | No | Launch from ground |
| `jump_air.glb` | Yes | Mid-air hover/fall pose |
| `jump_land.glb` | No | Landing impact and recovery |
| `fall.glb` | Yes | Extended falling loop |
| `turn_left.glb` | No | 90-degree turn in place |
| `turn_right.glb` | No | 90-degree turn in place |

## Optional / Nice to Have

| File | Loop | Description |
|------|------|-------------|
| `idle_combat.glb` | Yes | Idle while weapon drawn |
| `walk_combat.glb` | Yes | Walk with weapon ready |
| `run_combat.glb` | Yes | Run with weapon ready |
| `swim_idle.glb` | Yes | Treading water |
| `swim_forward.glb` | Yes | Swimming movement |
