# Utility Animations

Interaction and world-use animations.

| File | Loop | Description |
|------|------|-------------|
| `interact.glb` | No | Generic interact (pull lever, press button) |
| `pickup.glb` | No | Bend down and pick up item |
| `open_chest.glb` | No | Kneel and open a container |
| `craft.glb` | Yes | Crafting station work loop |
| `drink.glb` | No | Consume a potion |
| `read.glb` | Yes | Reading a scroll or book |
| `climb_start.glb` | No | Grab ledge and begin climbing |
| `climb_loop.glb` | Yes | Climbing movement |
| `climb_top.glb` | No | Mantle over ledge |
